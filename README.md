# servicenow-employee-offboarding

## How It Works

1. HR or the manager submits an employee offboarding request.
2. The request captures the employee and exit details.
3. Offboarding tasks are created and assigned to the required teams.
4. Teams complete tasks such as asset return and access removal.
5. The request status is updated as tasks are completed.
6. Email notifications are sent for important updates.
7. The offboarding request is closed after all required tasks are completed.

## My Configuration

- Created a custom table and form for offboarding requests.
- Added fields for employee and exit details.
- Used UI Policies and Client Scripts for form behavior.
- Created Business Rules for request processing.
- Used Flow Designer to automate offboarding tasks.
- Configured email notifications.
- Created reports to track offboarding requests.
- Tested the complete process from request creation to closure.

## Result

The project provides a simple way to track employee offboarding activities from request creation to completion. I tested the workflow to make sure the required tasks, notifications, and status updates work correctly.
